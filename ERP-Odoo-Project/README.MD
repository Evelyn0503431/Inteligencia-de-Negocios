# ERP Odoo - Proyecto de Implementación

Implementación de un ERP de código abierto (**Odoo 17 Community**) 
desplegado con Docker, incluyendo los módulos de Contabilidad, CRM, 
Ventas, Compras, Inventario y gestión de Proveedores.

---

## 🏢 Empresa ficticia

**Compañía Sanchez Tellez S.A. de C.V.**

Distribuidora de muebles y suministros de oficina en México. El caso de 
negocio simula la operación completa de una empresa que vende, compra, 
almacena y gestiona relaciones con clientes y proveedores.

---

## 🧰 Tecnologías utilizadas

- **Odoo 17.0 Community** — ERP de código abierto
- **PostgreSQL 15** — Base de datos
- **Docker + Docker Compose** — Contenerización
- **Windows + PowerShell** — Entorno de despliegue

---

## 📋 Requisitos previos

- Docker Desktop instalado y funcionando (con WSL 2 habilitado)
- 4 GB de RAM disponibles
- Puertos **8069** y **8072** libres en el host
- Windows 10/11, macOS o Linux
